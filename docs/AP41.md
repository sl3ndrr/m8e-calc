# AP41 · Gemeinsames Button-Feedback

Basis: main `65ce593bc2fe7065c3f43d29502f2023b49cf58b`, Branch
`feat/ap41-button-feedback`. AP41 war in Roadmap, Branches und Issues frei.
Keine Dependency-Änderung, kein Merge, Release, Tag oder manueller Deploy.

## Ursache und Änderung

Der gemeinsame Button wechselte von Full (9999 bei 16px root) bzw. Large zu
Small (8) mit Spatial Fast (Dämpfungsratio 0,6). Dessen Werte über 1 interpolieren
weit unter den zulässigen Radius; Browser begrenzen das auf 0. Die Keypad-
Rollenregeln verdeckten den Fehler, Operatorprüfungen erfassten ihn daher nicht.
Motion 14 ändert diesen CSS-Vertrag nicht.

Press hält jetzt den Rollenradius konstant. Eine separate dekorative Oberfläche
trägt Hintergrund, Rand, Schatten und geclippten State-Layer; sie und der Inhalt
skalieren mit 0,97 und monotonem Effects Fast. Das native Klickziel und sein
Fokusring bleiben unverändert. Verbundene Buttons verschieben keine Nachbarn.
Selected behält die bestehenden round/square-Endpunkte, wechselt aber diskret,
ohne überschwingende Geometrie. Keine neuen Timer oder Runtime-Imports.

## Prüfung und Reproduktion

Der AP19-Recorder in `calculatorCapture.ts` erfasst zusätzlich alle vier Radien,
Host-/Surface-/Content-Transform, State-Layer, echte Hit-Geometrie und Fokus.
AP36 verwendet denselben Recorder für normale Buttons/IconButtons in Produktion
und Galerie: echte laufende Press-/Release-Frames, kurze Wiederholungen,
Pointer-Verlassen/-cancel, Space/Enter, Selected, Disabled, Motion-/OS-Abbruch
und Unmount. AP19 erhält seine Operator-/globalen Keyboardfälle und ergänzt
Ziffern, Löschen, Speicher und wissenschaftliche Funktionen.

Der bestehende AP36-Workflow enthält einen auf AP41 begrenzten Vergleich mit dem
gepinnten aktuellen main und dessen Original-Lockfile. Nur im Baseline-Paar sind
präzise erwartete Fehler zulässig: Der Test muss zuerst einen tatsächlichen
Nullradius-Frame nachweisen und Rohdaten/Zwischenbild sichern. Der Kandidat hat
keine solchen Ausnahmen. Produktion und Galerie werden separat gebaut.

```sh
npm ci --engine-strict
npm run tokens
git diff --exit-code src/styles/tokens.css
npm run check
npm run build:gallery
npx playwright install --with-deps chromium firefox webkit
npx playwright test --config=playwright.ap36.config.ts
npx playwright test e2e/calculator-rendering.spec.ts e2e/calculator-native-zoom.spec.ts e2e/simple-calculator.spec.ts e2e/scientific.spec.ts --project=chromium --trace=on --workers=1
npm run test:e2e:gallery
```

Prüfstatus: lokale Installation durch HTTP 403 des Paketregister-Netzwerkfilters
blockiert. Tatsächliche PR-CI-Ergebnisse und Build-/Frame-Nachweise werden nach
Abschluss eingetragen; vorbereitete Tests sind noch kein bestandener Lauf.
Keine Snapshotupdates oder gelockerten Grenzwerte.
